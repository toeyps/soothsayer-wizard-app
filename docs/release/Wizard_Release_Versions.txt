 0.12.0  —  2026-10-21  (MINOR)
==========================================================================
[ฟีเจอร์ใหม่]
 - ปุ่ม Export results ที่แถบล่างของหน้าต่าง Build Model (กดได้เมื่อโมเดลทุกตัว Complete)
   - checklist บอกว่าอะไรครบ/ขาด, ดูตัวอย่างโครงสร้างไฟล์และเนื้อไฟล์ (Peek)
   - เลือกโฟลเดอร์เอง แอปสร้างโฟลเดอร์ใหม่ทุกครั้ง ไม่เขียนทับของเดิม
   - ได้ machine_info.json + models/<ชื่อ>.json และ .csv ต่อโมเดล (ไม่มี .pkl, ไม่มีข้อมูลดิบ, ไม่มีชื่ออัลกอริทึม)
   - ระหว่าง export ล็อกช่องตั้งค่า, ยกเลิกได้, เปิดโฟลเดอร์ผลลัพธ์ได้
 - ข้อมูลเครื่อง: Plant, Machine, Machine tag (บังคับ) + Notes; ชื่อ project = "Plant · Machine" ห้ามซ้ำ
   - แก้ได้ที่ Project details (ปุ่ม Rename บน Recent card, เมนูชื่อ project บน title bar, เมนูแอป)
   - บรรทัด time zone ของข้อมูลใน Step 2 ใช้ประทับเวลาในไฟล์ export
   - Duplicate project ต่อท้ายชื่อ machine ด้วย " (Copy)" และคงสถานะ Complete
 - Running status (เครื่องทำงานเมื่อ sensor ใดสูงกว่าค่าเท่าไร) ส่งออกใน machine_info.json
 - ชื่อโมเดลห้ามซ้ำทั้ง project; โมเดลใหม่ได้ชื่อเริ่มต้นไม่ซ้ำเอง
 - โมเดลที่ไม่มี Category กด Mark complete ไม่ได้
 - ตรวจสเปกก่อน export (input = output, X = Y, ชื่อ Failure Group ซ้ำ, ปัญหารายโมเดล)
[พฤติกรรมที่เปลี่ยน — โปรดอ่าน]
 - Mark complete ไม่เขียนไฟล์แล้ว แค่ตรวจและตั้ง Complete (ไฟล์เขียนตอน Export results เท่านั้น)
 - แก้ set point ของโมเดลที่ Complete แล้ว → กลับเป็น Incomplete ทันที
 - ช่วง cluster เป็น min < ค่า <= max (ค่าที่ตรงเส้นแบ่งอยู่ช่วงล่าง)
 - ขอบนอกของ cluster เปิด: ค่านอกช่วงได้คะแนนตาม cluster ริมสุด; ช่วงซ้อนกัน train แค่ cluster แรก
[แก้บั๊ก]
 - Dashboard autosave ไม่เขียนทับชื่อ/ข้อมูลเครื่อง/time zone ที่เพิ่งบันทึก
 - แก้ชื่อ project ได้ทางเดียว (Project details)
 - แก้ set point ระหว่างตรวจ Mark complete → โมเดลคง Incomplete
 - การตรวจ export ที่ล้มไม่ขึ้น "Export failed" แบบไม่มีคำอธิบาย
 - ชื่อไฟล์ที่ตรงกับชื่อ device ของ Windows (เช่น NUL) ถูกแปลงให้ปลอดภัย
[ลบออก]

 0.11.1  —  2026-10-19  (PATCH)
==========================================================================
[แก้บั๊ก]
 - ไฟล์จาก historian (เช่น 01-Jan-25 12:00 AM) โหลดแล้วได้วันที่ถูกต้อง (0.11.0 ยังอ่านผิด)
   - สาเหตุหนึ่งคืออักขระซ่อน (UTF-8 BOM) หน้าชื่อคอลัมน์แรก — ตอนนี้ตัดทิ้งทุกหัวคอลัมน์ (ไฟล์ข้อมูลและ mapping)
 - เลิกเตือน "Duplicate column ... found in file 1, file 2" สำหรับ sensor ที่มีในหลายไฟล์
   (คอลัมน์ซ้ำภายในไฟล์เดียวยังเตือนเหมือนเดิม)
[ฟีเจอร์ใหม่ — อ่านวันเวลาได้ครอบคลุมขึ้นมาก]
 - ชื่อเดือนภาษาอังกฤษ (ย่อ/เต็ม) และภาษาไทย ทุกลำดับ เช่น 01-Jan-25, Jan 31, 2025, 31 มกราคม 2568
 - ปี 2 หลัก (อ่านเป็น 20YY; ปีไทย 2 หลักเป็น พ.ศ. 25YY) และเลขไทย
 - ชื่อวันนำหน้า และเขตเวลาท้าย (Z, UTC, GMT+0700, +07:00) — ใช้เวลาตามที่เขียน
 - AM/PM ทุกแบบ รวมคำว่า น. / เวลา / พ.ศ.
 - ตัวเลขติดกัน (20250131130500), ISO ไม่มีตัวคั่น (T130500), ทศนิยมแบบจุลภาค
 - คอลัมน์เวลาเป็นตัวเลขล้วน: Excel serial date และ Unix epoch (วินาที/มิลลิวินาที, UTC)
 - กล่องเตือนสีเหลืองหน้า Import บอกรูปแบบที่อ่านได้ของแต่ละไฟล์ และจำนวนแถวที่อ่านวันเวลาไม่ได้
 - หน้า Import แสดงตัวอย่างรูปแบบที่รองรับเพิ่มเติม

   - อ่านได้ทั้ง เดือน/วัน/ปี, วัน/เดือน/ปี (คั่นด้วย / . หรือ -), ปี/เดือน/วัน, AM/PM และ ISO ที่ลงท้าย Z

   - หลายไฟล์ที่เขียนวันเวลาคนละแบบ รวมกันตามเวลาได้ตรงกัน
   - หน้า Import แสดงรูปแบบที่อ่านได้ครบ 8 แบบ และบอกว่าปีต้องเป็น 4 หลัก

 0.10.0  —  2026-10-15  (MINOR)
==========================================================================
[Breaking changes — workspace เก่าเปิดได้ แต่พฤติกรรมเปลี่ยน]
 - Health score คำนวณจาก "ค่าเฉลี่ยราย 1 ชั่วโมง" (ไม่ใช่ทุกแถว) — เส้นเรียบขึ้น คะแนนมักสูงขึ้น
   อาการที่สั้นกว่า 1 ชม. จะถูกเฉลี่ยจนเบาลง
   - ชั่วโมงที่เครื่องไม่เดิน = ไม่มีคะแนน
   - Clustering: ชั่วโมงที่ย้าย cluster ระหว่างชั่วโมง = "no score"
   - โมเดลที่ Complete ไว้แล้วยัง Complete แต่จะขึ้นข้อความให้ Mark complete ใหม่
 - ช่วง Scoring เหลือแค่ วันเริ่ม -> วันจบ (เลิกแยก Normal/Known problem, event time, lead time)
 - Clustering ได้ไม่เกิน 5 cluster, โมเดลใหม่เริ่มที่ 1 cluster
 - สูตรเก่าแบบ Excel round($A, 2) ถูกแปลงอัตโนมัติเป็น round($A * 100) / 100 (สูตรเดิมคำนวณผิด)
 - สูตรที่สะกดชื่อ/ฟังก์ชันผิด ถูกปฏิเสธพร้อมบอกวิธีแก้ (เดิมได้ sensor ว่างแต่ขึ้น "Updated")
[ฟีเจอร์ใหม่]

 - ชื่อ sensor แสดง description ก่อนแล้วตามด้วย tag ทุกที่; ตัวเลือก sensor/สีแบบเดียวกันทั้งแอป
   (ค้นหา description/tag/หน่วย/component, เลือกหลายตัวแล้วกด OK) ไม่แสดงรหัสสี hex
   - ค่าที่ผู้ใช้พิมพ์แสดงตามที่พิมพ์ (เช่น > 0.0005 ไม่ถูกปัด)
 - ตัวแก้สูตร special sensor ใหม่: เติมคำอัตโนมัติ, ขีดเส้นใต้จุดผิด, ดูผลบนกราฟก่อนบันทึก,
   Quick build (Average/Sum/Median/ปัดทศนิยม), ฟังก์ชัน ln

 - หน้าตั้ง Running condition ใหม่: timeline ช่วง Train/Scoring, บอกผลกระทบก่อนกด Apply
 - ตัวดักข้อมูลก่อน Train: ช่วงเวลานอกข้อมูล หรือเงื่อนไขที่ไม่มีแถวผ่าน จะบล็อกพร้อมเหตุผล
 - Workbench จัดหน้าใหม่: แถบ KPI, score ruler, กราฟ set point + คะแนนซูมไปด้วยกัน,
   แท็บบอกสถานะเป็นคำ, หน้าต่าง Compare predictors (เดิม Sub-models)
 - ลบ tag บนกราฟทีละจุดได้ + แท็บ Tagged points เทียบค่าทุก tag
