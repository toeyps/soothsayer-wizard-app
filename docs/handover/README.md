## วิธีเขียนบันทึก (สำหรับทุก session และ agent)

- **ต่อท้ายไฟล์ของเดือนปัจจุบัน** `docs/handover/YYYY-MM.md` — ถ้ายังไม่มีไฟล์ของเดือนนั้น ให้สร้างใหม่โดยคัดลอกหัวไฟล์ 8 บรรทัดแรกจากไฟล์เดือนก่อนแล้วแก้ชื่อเดือน และเพิ่มแถวในตารางด้านบน
- **1 งาน = 1 หัวข้อ** รูปแบบเดียวเสมอ:

  ```markdown
  ## 🆕 2026-10-09 — หัวข้อสั้นๆ ว่าทำอะไร (session/agent ที่ทำ ถ้าระบุได้)

  สรุป 1–3 บรรทัด
  - สิ่งที่ผู้ใช้ตัดสินใจและเหตุผล / สิ่งที่ลองแล้วไม่ใช้
  - ตรวจอะไรแล้ว และอะไรที่ยังไม่ได้ทดสอบในแอปจริง
  - ไฟล์ที่แก้ · สถานะ commit / push
  ```

- ห้ามแก้หรือย้ายบันทึกเก่า (ต่อท้ายอย่างเดียว) — ถ้าข้อมูลเก่าผิด ให้เขียนบันทึกใหม่ที่อ้างถึงอันเดิม
- **บันทึกนี้ไม่แทน `PROJECT_OVERVIEW.md`**: ถ้างานที่ทำเปลี่ยน "สถานะปัจจุบัน" (เวอร์ชันล่าสุด, งานที่รอทดสอบ/รอ push, วิธีรัน, โครงสร้างหลัก) ให้แก้ `PROJECT_OVERVIEW.md` ให้ตรงด้วยในรอบเดียวกัน
- Release (`release-agent`) อ่านบันทึกตั้งแต่วันที่ของเวอร์ชันก่อนหน้า — ดูวันที่ได้จาก [`../release/CHANGELOG.md`](../release/CHANGELOG.md) แล้วเปิดเฉพาะไฟล์เดือนที่เกี่ยวข้อง
