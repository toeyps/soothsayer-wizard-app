ทดสอบบนโปรแกรมที่ติดตั้งจาก installer เท่านั้น — ไม่ใช่โหมด dev เพราะการตั้งค่าความปลอดภัยและตำแหน่งไฟล์เบื้องหลังต่างกัน บั๊กบางตัวโผล่เฉพาะในตัวติดตั้งจริง

วิธีใช้: กรอกชื่อผู้ทดสอบด้านล่างก่อน แล้วไล่ทำทีละข้อ ติ๊ก ผ่าน / ไม่ผ่าน / ข้าม และจดสิ่งที่เจอในช่องด้านขวาให้ละเอียด (ทำอะไรถึงเจอ เห็นอะไร ควรเห็นอะไร) — ยิ่งละเอียดยิ่งแก้ได้ตรงจุด

ตอนจบ: กดปุ่ม บันทึกผลเป็นไฟล์ ที่แถบล่าง แล้วส่งไฟล์ที่ได้กลับมา · ถ้าทำไม่จบในครั้งเดียว ปิดหน้าต่างได้เลย งานถูกจำไว้ให้อัตโนมัติ (หรือกดบันทึกไฟล์ไว้แล้วค่อยกด “เปิดไฟล์ผลเดิม” ทีหลัง)

ใหม่ ฟีเจอร์ใหม่ ยังไม่เคยมีใครลอง จับตา จุดที่เคยมีปัญหา sidecar ส่วนที่เรียกโปรแกรมเบื้องหลัง
