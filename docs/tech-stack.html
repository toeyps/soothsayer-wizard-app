Technical Stack — Reference Sheet

Wizard (Soothsayer‑Wizard)

Desktop app for CSV sensor-data import, dashboard exploration (table / line / scatter / pair-plot), Failure Group tagging, and Predictive Model training (Individual, Clustering, Relationship).

Package version 0.2.1 Shell Tauri v2 Architecture 3-tier: React ↔ Rust core ↔ Python sidecar Tests 798 passing / 49 files

Architecture

how the three tiers talk
React frontend UI, charts, workspace state — no React Router, view switching is local state via a ?window= query param per Tauri window
Tauri IPC (invoke / commands) — 20 registered commands
Rust core CSV parsing, in-RAM columnar store, chart query pipeline, clustering, formula engine, window management
stdin / stdout, JSON only — spawned as a Tauri externalBin sidecar
Python sidecar Relationship-model fitting only — compiled to a native binary, never shipped as raw .py
