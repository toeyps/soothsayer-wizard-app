# ลำดับการทดสอบ — ทำทีละรอบ รอบละชุดข้อมูลเดียว

ทั้งทีมใช้ **ตัวติดตั้งตัวเดียว คือเวอร์ชันล่าสุดที่ได้รับ** · แต่ละรอบใช้ **ชุดข้อมูลชุดเดียว** ทำหมวดในรอบนั้นให้จบก่อนขึ้นรอบถัดไป ไม่ต้องสลับไปมาระหว่างชุดข้อมูล
ไฟล์ข้อมูลทดสอบได้จากทีมพัฒนา แยกเป็นชุด (WF, IMP, TS, EXP) · ข้อไหนใช้ไฟล์ไหน ดูบรรทัด "ไฟล์ที่ใช้" ในข้อนั้น · เลือก "รอบ" ที่แถบด้านบนของแบบฟอร์มเพื่อดูเฉพาะข้อของรอบนั้นตามลำดับที่ควรทำ

| รอบ | ชุดข้อมูล | หมวด / ข้อ | ประมาณ |
|---|---|---|---|
| 0 | — | เตรียมเครื่องและติดตั้งโปรแกรม | 15 นาที |
| 1 | ชุด WF — เครื่องสูบน้ำ P-101 | workflow WFA–WFD แล้วหมวดทีละฟังก์ชันส่วนใหญ่ | 1–2 วัน |

## รอบ 0 — เตรียมเครื่องและติดตั้งโปรแกรม (ครั้งเดียว)
1. PREP-7: สำรองโฟลเดอร์ `%APPDATA%\com.prompt-solution.tauri-app` (ถ้าเครื่องเคยมีโปรแกรมนี้)
2. PREP-6: รับไฟล์ข้อมูลทดสอบจากทีมพัฒนาให้ครบทุกชุด (WF, IMP, TS, EXP) แล้วเก็บไว้ที่เดียว อย่าย้ายหลังสร้างโปรเจกต์แล้ว
3. PREP-1: ตรวจไฟล์ติดตั้งที่ได้รับ (ส่วนที่ผู้ทดสอบตรวจได้ตามที่ข้อนั้นบอก)
4. PREP-2: ติดตั้งโปรแกรม (ถ้ามีตัวเก่าในเครื่อง ถอนออกก่อนโดย **ไม่ติ๊ก** "Delete the application data")
5. เปิดแบบฟอร์มนี้แล้วกด "ล้างผลทั้งหมด" ถ้ามีผลรอบก่อนค้างอยู่

1. **WFA → WFB → WFC → WFD** ตามลำดับ (WFB–WFD ใช้โปรเจกต์ที่ได้จาก WFA ต่อ)
2. ใช้โปรเจกต์เดียวกันนี้ทำหมวดทีละฟังก์ชัน: APP, LAY, SEN, SEL, FIL, HL, TIME, LINE, SCAT, PAIR, FG, VIS, PER, ERR
3. หมวด **BMW** ทุกข้อ ยกเว้นข้อ Export (รอบ 5) และข้อที่ต้องใช้โปรเจกต์จากเวอร์ชันเก่า (ข้ามได้)
4. ข้อพิเศษในรอบนี้ที่ใช้ไฟล์จากชุดอื่น: BMW-201, BMW-212, FG-26, VIS-3, PER-15, PER-19 — ดูบรรทัด "ไฟล์ที่ใช้" ในข้อนั้น

## ข้อไหนอยู่รอบไหน (แบบฟอร์ม HTML อ่านจากกล่องนี้ — อย่าลบ)

`scripts/build-manual-test-html.py` อ่านกล่องข้างล่างเพื่อใส่ป้าย "รอบ N" / "ข้ามได้" ให้ทุกข้อในแบบฟอร์ม และ `--check` จะไม่ผ่านถ้ามีข้อที่ไม่มีรอบ อยู่สองรอบ หรือกล่องนี้อ้างถึงข้อที่ไม่มีอยู่จริง
กติกา: หนึ่งบรรทัดต่อหนึ่งรอบ `รอบ: รายการ` (รอบ = เลขในตารางด้านบน หรือ `skip` = แถว "ข้ามได้") · `BMW-378` = ข้อเดียว · `BMW-389..392` = ทุกข้อที่มีอยู่ในช่วงนั้น (ปลายทั้งสองต้องมีจริง) · `BMW` (ชื่อหมวด) = ทุกข้อของหมวดที่ไม่ได้ถูกระบุเป็นรายข้อไว้ในบรรทัดไหนเลย · ลำดับในบรรทัด = ลำดับหมวดที่แบบฟอร์มแสดงเมื่อเลือกรอบนั้น
เพิ่มข้อใหม่ในหมวดที่อยู่ในกล่องเป็นชื่อหมวด ไม่ต้องแก้กล่องนี้ · ถ้าข้อใหม่ต้องอยู่รอบอื่นจากหมวดของมัน ให้เติม id ลงบรรทัดของรอบนั้น
