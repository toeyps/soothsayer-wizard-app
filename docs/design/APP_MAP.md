# Wizard — App Map (screens, flows, latest designs)

**Owner:** `ui-design-lead` (Fable). Update the "Latest design" and "State" columns whenever a design round finishes. Detailed decisions live in `docs/PROJECT_HANDOVER.md` (search the SPEC FINAL entries).

## Main flow

```
Welcome (Get started) ──New project──▶ Step 1 Which machine is this? (Plant · Machine · tag · Notes; export design 2026-10-20) ──▶ Step 2 Add sensor data + tag names (+ time zone of the data) ──▶ Step 3 Failure groups (SPEC FINAL 2026-10-09, phase 3, skippable) ──Open Dashboard──▶ Dashboard (lands on the FG tab)
        └──Recent project──────────────────────────────────────────────────────────────────────────────────────▶ Dashboard
        └──Rename on a card / title-bar project name ▾ ──▶ Project details (Plant · Machine · tag · Notes · time zone; one save)
Dashboard ──Build Model──▶ Build Model window (Workbench)
   Workbench: Running condition (Step 1; + "Machine is running when … is above …" for the export) → per sensor: model kind tabs I/R/C
              → page 1 "Model fit" (settings, Train, analysis charts)
              → page 2 "Health score" (set points, checks, score chart, Mark complete = validate only, no files)
              → Export results (bottom bar → readiness checklist → confirm sensors without a component → write every Complete model's files once; export design 2026-10-20)
Dashboard ──Add special sensor──▶ formula editor + Quick build (computed sensor; SPEC FINAL, phase 5 — Rust half shipped locally)
```

Windows: `main` (welcome → setup → dashboard), `build-model`, `add-sensor`.
