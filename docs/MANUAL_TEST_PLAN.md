  - ถอนการติดตั้ง Wizard ตัวเดิมออกจาก Windows

## IMP

### หน้า Import (3 ขั้น)

_Step 0 = เลือกว่าจะสร้างใหม่หรือเปิดของเดิม · Step 1 = ตั้งชื่อโปรเจกต์ · Step 2 = ใส่ข้อมูล_

- [ ] **IMP-1 — Step 0 — หน้าเลือกทางเข้า**
  - ดูหน้าแรก
  - **คาดหวัง:** มีทั้งปุ่มสร้างโปรเจกต์ใหม่ และรายการ Recent Workspaces — ตอนอยู่ step 0 ต้องไม่มี sidebar รายการ workspace ซ้ำอีกชุด

- [ ] **IMP-2 — รายการ Recent Workspaces**
  - ดูชื่อ / วันเวลาที่แก้ล่าสุด
  - ดูลำดับ
  - **คาดหวัง:** เรียงตัวที่แก้ล่าสุดขึ้นก่อน ชื่อและเวลาตรงกับที่เพิ่งทำจริง

- [ ] **IMP-3 — เมนู 3 จุด ของแต่ละ workspace → Delete**
  - กดเมนูของ workspace ที่ไม่ใช้แล้ว
  - กด Delete
  - กดที่อื่นเพื่อปิดเมนู
  - **คาดหวัง:** ลบแล้วหายจากรายการทันที, กดที่อื่นแล้วเมนูปิด, ไม่ลบตัวอื่นพลาด

- [ ] **IMP-4 — เปิด workspace เดิมแล้วเข้าหน้าที่ค้างไว้**
  - เปิด workspace ที่ปิดค้างไว้ตอนอยู่หน้า Dashboard
  - ทำซ้ำกับตัวที่ปิดค้างตอนอยู่แท็บ Failure Groups
  - **คาดหวัง:** เข้าหน้าเดิมที่ค้างไว้ (`lastRoute`) ไม่ใช่เด้งกลับหน้าแรกเสมอ

- [ ] **IMP-5 — workspace ที่ไฟล์ CSV ต้นทางถูกย้าย/ลบไปแล้ว**
  - ย้ายไฟล์ CSV ต้นทางออกจากที่เดิม
  - เปิด workspace นั้น
  - **คาดหวัง:** ขึ้นข้อความบอกว่าหาไฟล์ไม่เจอแบบอ่านรู้เรื่อง ไม่ crash ไม่จอขาว

- [ ] **IMP-6 — Step 1 — สร้างโปรเจกต์**
  - ปล่อยชื่อว่างไว้แล้วดูปุ่ม Continue
  - พิมพ์ชื่อ + description
  - กด Back
  - **คาดหวัง:** Continue ใช้ไม่ได้จนกว่าจะมีชื่อ, Back กลับ step 0 ได้

- [ ] **IMP-7 — ตั้งชื่อโปรเจกต์ซ้ำกับที่มีอยู่**
  - ตั้งชื่อให้ตรงกับ workspace เดิมเป๊ะ ๆ
  - ทำต่อจนจบ
  - **คาดหวัง:** ดูว่าเตือนหรือปล่อยผ่าน — ถ้าปล่อยผ่านแล้วเปิดผิดตัวทีหลัง ให้บันทึกไว้

- [ ] **IMP-8 — Step indicator กดย้อนกลับได้อย่างเดียว**
  - อยู่ step 2 แล้วกดวงกลม step 1
  - อยู่ step 1 แล้วลองกดวงกลม step 2
  - **คาดหวัง:** ย้อนกลับได้ แต่กดข้ามไปข้างหน้าไม่ได้

- [ ] **IMP-9 — Step 2 — อัปโหลด CSV ข้อมูล 1 ไฟล์**
  - เลือกไฟล์ CSV ขนาดปกติ
  - **คาดหวัง:** ขึ้นชื่อไฟล์ + สรุปจำนวนแถว/คอลัมน์

- [ ] **IMP-10 — อัปโหลดหลายไฟล์แล้ว merge**
  - เลือก CSV หลายไฟล์ที่มีคอลัมน์เหมือนกัน
  - **คาดหวัง:** รวมเป็นชุดเดียว จำนวนแถวเท่ากับผลรวม, คอลัมน์ timestamp ถูกจับเป็นตัวเดียว

- [ ] **IMP-11 — Data validation summary**
  - ดูสรุปหลังอัปโหลด
  - **คาดหวัง:** บอกจำนวนแถว, คอลัมน์, และแถวที่ timestamp parse ไม่ได้ — ลองกับไฟล์ที่จงใจมี timestamp เสียแล้วดูว่าตัวเลขตรง

- [ ] **IMP-12 — อัปโหลด mapping CSV**
  - เลือกไฟล์ mapping
  - **คาดหวัง:** แสดงว่าจับคู่ tag ได้กี่ตัว ไม่ได้กี่ตัว

- [ ] **IMP-13 — จับคู่ tag ที่ระบบจับไม่ได้ ด้วยมือ**
  - หา tag ที่จับคู่ไม่ได้
  - เลือกคู่เอง
  - **คาดหวัง:** เลือกได้และผลไปโผล่ที่ description/unit/component ของ sensor นั้นใน Dashboard

- [ ] **IMP-14 — Alarm setpoint เข้ามาจาก mapping**
  - ใช้ mapping ที่มี ALARM_L / ALARM_LL / ALARM_H / ALARM_HH
  - เข้า Dashboard แล้วเปิด alarm ของ sensor นั้น
  - **คาดหวัง:** เส้น alarm ขึ้นตรงค่าที่อยู่ใน mapping — sensor ที่ไม่มีค่าในคอลัมน์นั้นต้อง**ไม่ขึ้นเส้นที่ 0**

- [ ] **IMP-15 — ไฟล์ผิดรูปแบบ**
  - ลองไฟล์ที่ไม่มีคอลัมน์ timestamp
  - ลองไฟล์ว่าง
  - ลองไฟล์ที่ไม่ใช่ CSV
  - **คาดหวัง:** ทุกกรณีขึ้นข้อความบอกสาเหตุ ไม่ crash และยังกดทำอย่างอื่นต่อได้

- [ ] **IMP-16 — ไฟล์ใหญ่จริง**
  - อัปโหลด CSV ขนาดหลายร้อย MB
  - **คาดหวัง:** มีสัญญาณว่ากำลังทำงาน (ไม่ค้างแบบเงียบ), จบแล้วเข้า Dashboard ได้, จับเวลาไว้ด้วยว่านานเท่าไร

- [ ] **IMP-17 — กด Continue เข้า Dashboard**
  - กด Continue ที่ step 2
  - **คาดหวัง:** เข้า Dashboard พร้อมชื่อ workspace ที่ตั้งไว้บน title bar

  - ดูว่าทั้ง 4 label (Name/Description/Unit/Component) มีเครื่องหมาย * สีแดงกำกับ
  - กรอกครบทั้ง 4 ช่องแล้วกด Add sensor
  - **คาดหวัง:** สร้างสำเร็จ และค่าไปโผล่ในแท็บ Selected Sensor ของ Dashboard ครบทั้ง 3 ช่อง (Description/Unit/Component)

  - **คาดหวัง:** ขึ้น toast ✓, ฟอร์มถูกล้างพร้อมสร้างตัวถัดไป, หน้าต่างยังเปิดอยู่, กราฟฝั่ง Dashboard อัปเดตทันที

  - **คาดหวัง:** มีอยู่ในรายการและค้นหาเจอ

  - พิมพ์สูตรที่ซ้อนวงเล็บลึกมาก
  - **คาดหวัง:** ทุกกรณีขึ้น error อ่านรู้เรื่อง ไม่ crash หน้าต่าง

- [ ] **SPC-12 — ตั้งชื่อ special sensor ซ้ำกับคอลัมน์ดิบ**

  - **คาดหวัง:** ดูว่าเกิดอะไรขึ้น — คอลัมน์ดิบต้องไม่ถูกทับ (การสร้างตั้งใจให้ append ไม่ replace) จดพฤติกรรมจริงไว้

- [ ] **SPC-13 — ปุ่มเครื่องหมาย (+/−/×/÷) ต้องปิดจริงตอนเลือก shortcut ไว้** 🆕
  - เลือก sensor ตั้งแต่ 2 ตัวขึ้นไป
  - เลือก shortcut เช่น "Sum all" หรือ "Compare one against the rest"
  - ดูแถบ "Combine with operators" (เครื่องหมาย +/−/×/÷ ระหว่างแต่ละคู่ sensor)
  - ลองกดเครื่องหมายตัวใดตัวหนึ่ง
  - เลิกเลือก shortcut (กดซ้ำ) แล้วลองกดเครื่องหมายอีกที
  - **คาดหวัง:** ตอนเลือก shortcut ไว้ แถบเครื่องหมายต้องจางลง กดแล้ว**ไม่มีอะไรเกิดขึ้นเลย** (ไม่เปิด popover เลือกเครื่องหมายใหม่ ไม่เผลอไปยกเลิก shortcut) มีข้อความอธิบายว่า "A shortcut below is selected..." — พอเลิกเลือก shortcut แถบต้องสว่างขึ้นและกดได้ปกติทันที (ก่อนหน้านี้กดได้ตลอดแม้เลือก shortcut ไว้ ซึ่งเผลอไปยกเลิก shortcut แบบไม่มีอะไรโชว์ให้เห็น)

- [ ] **SPC-14 — แก้ไขตัวเลือก sensor ระหว่างตั้งค่า ไม่ทำให้ Description/Unit/Component หาย** 🆕
  - เลือก sensor ไว้ 1 ตัว
  - กรอก Description, Unit, Component ไว้ (ยังไม่กด Add sensor)
  - เพิ่มหรือลด sensor อีกตัวหนึ่งในการเลือก (เช่น ติ๊กเพิ่มอีกตัว หรือเอาตัวหนึ่งออกแต่ไม่ให้เหลือ 0 ตัว)
  - **คาดหวัง:** **ค่าที่กรอกไว้ทั้ง 3 ช่องต้องยังอยู่ครบ ไม่หายไปเงียบ ๆ** — ช่องพวกนี้อธิบาย sensor ใหม่ที่กำลังจะสร้าง ไม่ใช่ตัวที่เลือกไว้เป็น input จึงไม่ควรถูกล้างตามการปรับตัวเลือก (ช่องจะถูกล้างเฉพาะตอนเอา sensor ออกจนเหลือ 0 ตัวเท่านั้น — นั่นคือ "เริ่มใหม่")

- [ ] **MNG-1 — แท็บ Manage แสดงรายการครบ** 🆕

- [ ] **MNG-2 — สูตร/operation อ่านออก** 🆕

  - **คาดหวัง:** สูตรแสดงตามที่พิมพ์, operation แสดงเป็น `sum(a, b)` หรือ `a + 10` ไม่ใช่ JSON ดิบ

- [ ] **MNG-3 — ช่องค้นหา** 🆕
  - พิมพ์ชื่อ
  - พิมพ์คำใน description
  - พิมพ์บางส่วนของสูตร

- [ ] **MNG-4 — ลบตัวที่ไม่มีใครใช้** 🆕

  - กดถังขยะ

  - **คาดหวัง:** แถวกลับมาเหมือนเดิม และ**ฝั่ง Dashboard ต้องไม่เคยรู้เรื่องการลบเลย** (กราฟไม่กระพริบ)

  - **คาดหวัง:** sensor หายจากแผง Sensor และจากกราฟ

  - **คาดหวัง:** chip "on chart" ขึ้นที่แถว แต่ปุ่มลบยัง**กดได้** และพอลบจริงเส้นหายจากกราฟให้อัตโนมัติ

  - ไปลบ A
  - **คาดหวัง:** ปุ่มลบของ A ถูกปิด, มี chip 🔒 "Used by 1 sensor" กดแล้วกางบอกว่า B ใช้อยู่ และบอกให้ลบ B ก่อน

- [ ] **MNG-9 — ลบตัวที่โมเดลใน Failure Group ใช้อยู่ → ต้องกดไม่ได้** 🆕

  - ไปลบมัน
  - **คาดหวัง:** ปุ่มลบถูกปิด, chip บอกจำนวนโมเดล, กางแล้วเห็นชื่อโมเดล + ช่องที่อ้าง (เช่น "— target sensor")

- [ ] **MNG-10 — เช็คให้ครบทั้ง 7 ช่องของโมเดล** 🆕

  - ลบ B
  - ดูปุ่มของ A
  - **คาดหวัง:** ลบได้ทีละตัวจากปลาย และตัวก่อนหน้าปลดล็อกทันทีที่ตัวถัดไปถูกลบ (ไม่ต้องปิดเปิดหน้าต่าง)

- [ ] **MNG-12 — ชื่อที่เป็นส่วนหนึ่งของอีกชื่อ** 🆕

  - สร้างตัวที่ 3 ที่ใช้สูตร `${test extend} + 1`
  - ไปดูปุ่มลบของ `test`
  - **คาดหวัง:** **`test` ต้องลบได้** (ไม่มีใครอ้างมันจริง) ส่วน `test extend` ต้องลบไม่ได้ — นี่คือเหตุผลที่ต้องแยก parser ไปฝั่ง Rust แทนการเช็คแบบ substring

  - ลบชื่อในช่อง Name ออก พิมพ์ชื่อใหม่
  - Save changes

- [ ] **EDT-3 — แก้สูตรแล้วค่าบนกราฟเปลี่ยนทันที** 🆕
  - ปัก special sensor ตัวหนึ่งบนกราฟ จำรูปเส้นไว้
  - แก้สูตรจาก `* 2` เป็น `* 5`
  - กด Save changes
  - **ห้ามติ๊ก sensor ออก-เข้า**
  - **คาดหวัง:** **เส้นบนกราฟเปลี่ยนเองภายในไม่กี่วินาที** โดยไม่ต้องไปแตะอะไรอีก (นี่คือสิ่งที่ `dataRevision` ทำ)

  - แก้ทั้ง 3 ช่องแล้ว Save
  - ไปดูแท็บ Selected Sensor
  - **คาดหวัง:** ข้อความใหม่ขึ้นทั้งในแท็บ Manage และในรายการ Selected Sensor

- [ ] **EDT-4b — บังคับกรอกครบ 4 ช่องในฟอร์มแก้ไข (เหมือน Create) — Component เลิก fallback เงียบ ๆ แล้ว** 🆕

  - **คาดหวัง:** ปุ่ม **Save changes จางลงกดไม่ได้ทันที** พร้อมข้อความบอกว่าขาด Component — **ก่อนหน้านี้เว้น Component ว่างได้แล้วมันจะ fallback เป็น "Uncategorized" เงียบ ๆ ตอนนี้ต้องพิมพ์คำว่า Uncategorized เองถ้าต้องการ**

- [ ] **EDT-5 — แก้ operation — เปลี่ยน source sensors** 🆕

  - กด X ลบ chip ของ sensor หนึ่งออก
  - เลือกตัวใหม่จาก dropdown
  - Save
  - **คาดหวัง:** ค่าคำนวณใหม่ตาม input ชุดใหม่ และ dropdown ต้องไม่เสนอชื่อตัวมันเอง และไม่เสนอตัวที่เลือกไปแล้ว

- [ ] **EDT-6 — แก้ operation — เปลี่ยนชนิดและค่า** 🆕

  - เปลี่ยนตัวเลข Value
  - เปลี่ยนไปเป็น Square root
  - **คาดหวัง:** คำนวณถูก และพอเลือก op ที่ไม่ต้องใช้ค่า (sqrt/abs/...) ช่อง Value ต้องหายไปเอง

- [ ] **EDT-7 — จำนวน source sensor ต้องถูกต้อง** 🆕
  - operation แบบ single: ลองเพิ่มเป็น 2 ตัว
  - operation แบบ multi: ลองลดเหลือ 1 ตัว
  - **คาดหวัง:** ปุ่ม Save ถูกปิด และขึ้นข้อความบอกว่าต้องเลือกกี่ตัว

- [ ] **EDT-8 — ⭐ แก้ตัวต้นน้ำแล้วตัวปลายน้ำต้องเปลี่ยนตาม** 🆕
  - สร้าง A = `$TAG * 2`
  - สร้าง B = `${A} + 10`
  - สร้าง C = `${B} * 3`
  - ปักทั้ง A B C บนกราฟ จดค่าไว้
  - แก้ A เป็น `$TAG * 5`
  - Save
  - **คาดหวัง:** **ทั้ง B และ C ต้องเปลี่ยนค่าตามด้วย ไม่ใช่แค่ A** — toast ควรบอกว่า "recomputed 2 sensor(s) built on it". ถ้า B/C ไม่ขยับ = การ replay สายโซ่ไม่ทำงาน

- [ ] **EDT-9 — แก้ให้เกิดวงจร → ต้องถูกปฏิเสธ** 🆕
  - มี A → B → C อยู่แล้วจาก EDT-8
  - แก้ A ให้เป็น `${B} + 1`
  - Save
  - **คาดหวัง:** ขึ้น error สีแดงบอกว่าจะทำให้ขึ้นกับตัวเอง พร้อมบอกชื่อ B, ฟอร์มไม่ปิด, และ**ค่าของ A/B/C ต้องไม่ถูกแตะเลย**

- [ ] **EDT-10 — แก้ให้อ้างตัวเอง → ต้องถูกปฏิเสธ** 🆕
  - แก้ A ให้เป็น `${A} + 1`
  - Save
  - **คาดหวัง:** ถูกปฏิเสธเช่นกัน — ถ้าปล่อยผ่านค่าจะไต่ขึ้นทุกครั้งที่กด Save

- [ ] **EDT-11 — อ้างตัวที่อยู่ต้นน้ำได้ ไม่ใช่วงจร** 🆕
  - ในช่องสูตร (Formula) ของ C พิมพ์ทับข้อความเดิมด้วย `${A} + ${B}` โดยตรง (ไม่มีปุ่ม "รวม/combine" แยกต่างหาก — สูตรเป็นช่องข้อความที่พิมพ์ได้อิสระ)
  - Save
  - **คาดหวัง:** **ต้องผ่าน** — C อยู่ปลายน้ำอยู่แล้ว การอ้างขึ้นไปข้างบนไม่ใช่วงจร

- [ ] **EDT-12 — สูตรที่ไม่อ้าง sensor เลย** 🆕

## PER

### ปิดเปิดโปรแกรม & การบันทึก

_หมวดที่สำคัญที่สุด — ทุกอย่างข้างบนไม่มีความหมายถ้าเปิดกลับมาแล้วหาย_

- [ ] **PER-1 — ตั้งค่าทุกอย่างแล้วปิดเปิด**
  - ในหนึ่ง workspace: เลือก sensor หลายตัว, ซ่อนบางตัว, เปลี่ยนสี 2 ตัว, ตรึงแกน 1 ตัว, เปิด alarm 1 ตัว, ตั้ง filter, ตั้ง highlight by time, ตั้งช่วงเวลา, เปลี่ยน aggregation, ลากปรับขนาดแผง, ซ่อนแผงหนึ่ง, สลับไป Scatter แล้วตั้งแกน X/Y + ตรึงสเกล
  - ปิดโปรแกรมสนิท
  - เปิดใหม่แล้วเปิด workspace เดิม
  - **คาดหวัง:** **ทุกข้อข้างบนต้องกลับมาครบ** — ถ้าข้อไหนหาย ให้จดเฉพาะข้อนั้นไว้

- [ ] **PER-2 — แก้อะไรแล้วปิดโปรแกรมทันที**
  - เปลี่ยนสีเส้น 1 เส้น
  - กดปิดโปรแกรมภายใน 1 วินาที
  - เปิดกลับมา
  - **คาดหวัง:** สีที่เพิ่งเปลี่ยนยังอยู่ (autosave มี debounce 250ms + flush ก่อนปิด)

- [ ] **PER-3 — special sensor กลับมาพร้อมข้อมูลจริง**
  - สร้าง special sensor แล้วปักบนกราฟ
  - ปิดโปรแกรม เปิดใหม่
  - **คาดหวัง:** **เส้นมีข้อมูลจริง ไม่ใช่มีแต่ชื่อแล้วกราฟว่าง** — recipe ถูก replay ใหม่ตอนเปิด

- [ ] **PER-4 — special sensor ที่ต่อกันหลายชั้นกลับมาถูกลำดับ**
  - สร้าง A → B → C
  - ปิดเปิดโปรแกรม
  - ปักทั้งสามบนกราฟ
  - **คาดหวัง:** ค่าของทั้งสามถูกต้อง (replay ต้องเรียงตามลำดับสร้าง ไม่งั้น B จะหา A ไม่เจอ)

- [ ] **PER-5 — สลับ workspace ไปมา**
  - เปิด workspace A ตั้งค่าอย่างหนึ่ง
  - กลับหน้า Import เปิด workspace B ตั้งอีกอย่าง
  - กลับไป A
  - **คาดหวัง:** ค่าไม่ปนกันเลย

- [ ] **PER-6 — Rename workspace**
  - File → Rename Workspace
  - ตั้งชื่อใหม่
  - กลับหน้า Import
  - **คาดหวัง:** ชื่อใหม่ขึ้นทั้งบน title bar และในรายการ Recent Workspaces

- [ ] **PER-7 — เปิด workspace ที่สร้างจากเวอร์ชันเก่า**
  - เปิด workspace เก่าที่สร้างไว้ก่อนหน้านี้นาน ๆ
  - **คาดหวัง:** เปิดได้ ไม่ crash และโมเดลที่เคยเก็บ `groupNo` เดี่ยว ๆ ถูกแปลงเป็น `groupNos` เป็น array ให้อัตโนมัติ

- [ ] **PER-8 — ไฟล์ workspace อยู่ที่ไหน**
  - เปิด `%APPDATA%` แล้วหาโฟลเดอร์ของ `com.prompt-solution.tauri-app`
  - **คาดหวัง:** เห็นไฟล์ของ workspace และเวลาแก้ล่าสุดขยับตามที่ทำจริง

## ERR

### ความผิดพลาด & ขอบ

- [ ] **ERR-1 — Toast แจ้ง error**
  - ทำให้ backend fail (เช่น ย้ายไฟล์ CSV ออกระหว่างใช้งาน)
  - **คาดหวัง:** ขึ้น toast บอก ไม่ใช่เงียบ — ในตัวติดตั้งไม่มี console ให้ดู toast จึงเป็นทางเดียว

- [ ] **ERR-2 — ไม่มีจอขาว**
  - ลองทำอะไรแปลก ๆ ให้ component พัง
  - **คาดหวัง:** ErrorBoundary จับไว้และแสดงข้อความ ไม่ใช่จอขาวเปล่า

- [ ] **ERR-3 — ไฟล์ log ถูกเขียนจริง**
  - หลังเจอ error ไปหาไฟล์ log ใน `%APPDATA%` ของแอป
  - **คาดหวัง:** มีบรรทัดของ error ที่เพิ่งเจอ พร้อมรายละเอียด

- [ ] **ERR-4 — ปิดหน้าต่างลูกด้วยปุ่ม X**
  - เปิด Add Special Sensor แล้วกด X
  - เปิด Build Model แล้วกด X
  - **คาดหวัง:** ปิดได้ทั้งคู่ ไม่ค้าง (เคยมีบั๊ก capability `core:window:allow-destroy` ที่เห็นเฉพาะตอนติดตั้งจริง)

- [ ] **ERR-5 — เปิดหน้าต่างลูกซ้ำ**
  - กด Add Special Sensor ซ้ำ ๆ ตอนหน้าต่างเปิดอยู่แล้ว
  - **คาดหวัง:** ไม่เปิดซ้อนกันหลายบาน หรือถ้าเปิดได้ก็ต้องไม่ทำให้ข้อมูลเพี้ยน

- [ ] **ERR-6 — ไม่ได้เลือก sensor เลย**
  - Clear all แล้วสลับ chart type ไปมา
  - **คาดหวัง:** กราฟว่างพร้อมข้อความ ไม่มี error
