How it moves

  • Orbit camera. Left/right turns all the way round. Up/down tilts from almost straight down (80°) to just below the floor line (−10°), so it never flips.
  • Smooth, not jumpy. The view chases the pointer with a short smoothing; on release it keeps its speed and slows to a stop in about half a second.
  • The machine waits for you. Grabbing pauses the spin and the machine cycle (a dissolve already under way finishes first). 1.5 s after the glide ends, the spin resumes and the tilt eases back to the default over about 2 s, so the callouts and floor return to the framing you approved. The turn angle is kept.
  • Depth stays right from every side. Dot size, brightness and rim light are worked out from the camera each frame. Dots add light instead of covering each other, so no sorting is needed and no angle shows a wrong overlap.
  • Callouts follow the sensor spots as the machine turns.
  • Reduced motion: dragging still works; no glide, no auto spin, no cycle.
  • Setup rail mini: no drag. It is small, faint and sits behind the steps; grabbing it would compete with the form.
